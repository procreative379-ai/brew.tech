### 1. **Ошибка в навигации (ГЛАВНОЕ)**
**Проблема:** Все ссылки указывали на `brew.tech.html`, но этого файла не было.
- ❌ `href="brew.tech.html"`

### 2. **Отсутствие страницы 404**
**Решение:** Создан файл `404.html` — красивая страница ошибки в стиле BREW.TECH

**Что включает:**
- ✅ Фирменный дизайн (логотип, цвета, шрифты)

---

### 3. **Файл конфигурации сервера**
**Добавлен:** `.htaccess` для Apache

**Что он делает:**
- Перенаправляет все ошибки 404 на `404.html`
- Позволяет обращаться к страницам без расширения `.html` (опционально)
- Включает сжатие (gzip) для быстрой загрузки
- Кэширует статические файлы

## 🚀 Как развернуть

### Вариант 1: На своем хостинге (с Apache)
1. Загрузите все файлы на сервер
2. Убедитесь, что подключен модуль `mod_rewrite` и `mod_deflate`
3. Файл `.htaccess` должен быть в корневой папке сайта
4. Все работает! ✅

### Вариант 2: На GitHub Pages (статический хостинг)
1. Загрузите все файлы без `.htaccess`
2. GitHub Pages автоматически покажет 404.html при ошибке (нужно переименовать на `404.html`)
3. Все работает! ✅

### Вариант 3: На других хостингах
- Если используете Nginx: уберите `.htaccess` и добавьте конфиг в nginx.conf
- Если используете PHP хостинг: `.htaccess` обычно работает из коробки
- Проверьте документацию вашего хостера

## 🎨 Кастомизация 404 страницы

Если хотите изменить текст на странице 404, отредактируйте в файле `404.html`:

```html
<h1 class="error-title">Страница не найдена</h1>
<p class="error-desc">
  Похоже, вы пошли не в ту сторону.<br>Проверьте адрес или вернитесь на главную.
</p>
```

Измените текст, но не трогайте HTML структуру, чтобы не сломать стили.

## 🐛 Возможные проблемы

**Q: Клики на меню не работают?**
- A: Убедитесь, что используется обновленный `partials.js`

**Q: 404 страница не показывается?**
- A: Проверьте `.htaccess` в корневой папке (должен быть виден через FTP)
- Убедитесь, что модуль `mod_rewrite` включен на хостинге

**Q: Меню "бургер" не открывается?**
- A: Это может быть проблема с JavaScript. Откройте DevTools (F12) и проверьте консоль на ошибки
