## 🎨 OPTIONAL: ADD LANGUAGE SWITCHER

To let users switch languages, add this HTML snippet:

```html
<!-- In navigation, add: -->
<div class="lang-switcher">
  <a href="/index.html" hreflang="ru">РУ</a>
  <span>|</span>
  <a href="/index-en.html" hreflang="en">EN</a>
</div>
```

And this CSS:
```css
.lang-switcher {
  display: flex;
  gap: 8px;
  margin-left: auto;
  font-size: 12px;
}

.lang-switcher a {
  font-weight: 600;
  color: #666;
  transition: color 0.2s;
}

.lang-switcher a:hover {
  color: #0066ff;
}

.lang-switcher span {
  color: #ddd;
}
```
