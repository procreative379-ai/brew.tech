## ✅ How to Set Up (Choose One)

### Option 1: Upload All Files (Easiest) ⭐
Just upload all 22 files to your root directory. That's it!

```
yoursite.com/index.html        → Russian homepage
yoursite.com/index-en.html     → English homepage
```

### Option 2: Only Russian (Skip English Files)
If you only want Russian:
- Upload only the `-en.html` files NOT needed
- Upload only Russian files + shared files

### Option 3: Subdirectories
Create folders:
```
/ru/ → Russian version
/en/ → English version
```

## 🎨 Customization

If you want to customize translations:
1. Edit `i18n.js` file (658 translation pairs)
2. Search for the Russian text
3. Replace with your English translation
4. Save and upload

Example:
```javascript
// From:
"Кофемашина":"Coffee Machine",

// To:
"Кофемашина":"Espresso Machine",  // Your custom translation
```
