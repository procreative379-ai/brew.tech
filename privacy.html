Компания BREW.TECH ставит своей важнейшей целью соблюдение прав и свобод человека при обработке его персональных данных, включая защиту права на неприкосновенность частной жизни.

Настоящая политика применяется ко всей информации, которую Оператор может получить о посетителях веб-сайта https://brewtechology.ru.

4. Принципы обработки персональных данных

Принципы, которых придерживается BREW.TECH:

  • Законность: Все данные обрабатываются в соответствии с законодательством РФ
  • Справедливость: Данные обрабатываются открыто и честно
  • Целевое назначение: Данные используются только для заявленных целей
  • Минимизация: Собираются только необходимые данные
  • Точность: Данные актуальны и корректны
  • Безопасность: Данные защищены от несанкционированного доступа
  • Прозрачность: Пользователи информированы о обработке

6. Порядок обработки персональных данных

Сбор данных

Персональные данные собираются через:

  • Формы на сайте (контакты, заказы, подписка)
  • Автоматические системы отслеживания (cookies, аналитика)
  • Email-переписку с пользователями
  • Платежные системы и партнеры доставки

Хранение данных

Персональные данные хранятся:

  • На защищенных серверах компании
  • С использованием современных методов шифрования
  • Доступ ограничен авторизованными сотрудниками
  • Не дольше необходимого для целей обработки

Передача данных

Персональные данные передаются:

  • Партнерам по доставке (только необходимые данные)
  • Платежным системам (соответственно их политикам)
  • Государственным органам (по требованию закона)
  • НЕ передаются третьим лицам без согласия пользователя

Безопасность

BREW.TECH применяет следующие меры безопасности:

  • SSL/TLS шифрование для передачи данных
  • Защита от несанкционированного доступа
  • Регулярное резервное копирование
  • Обучение сотрудников по защите данных
  • Контроль доступа к базам данных
  • Мониторинг безопасности 24/7
